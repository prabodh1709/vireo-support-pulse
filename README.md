# Vireo Support Pulse

An AI-assisted internal support-operations dashboard for Vireo Audio.

## What it does

Vireo Support Pulse helps support leadership review:

- Complaint themes from customer support tickets
- SLA breach volume and exposure
- Tier 1 agent closure volume
- Transfer and policy risks
- Product-level SLA patterns
- Data quality and duplicate-ticket handling
- A measurable operational opportunity

## AI-Assisted Complaint Digest

The dashboard uses the Google Gemini API to summarize complaint themes from customer messages and agent notes.

AI is used only for qualitative complaint summarization.

The AI does NOT determine:

- Ticket counts
- SLA breach counts or rates
- Costs
- CSAT metrics
- Transfer counts
- Agent leaderboard totals

These metrics are calculated deterministically from the support dataset.

## Data Quality & Trust

Duplicate ticket IDs are handled before operational calculations. Helpdesk records are preferred over legacy imports when duplicate IDs are encountered.

The dashboard exposes raw row counts, unique ticket counts, duplicate rows removed, and CSAT response counts so users can understand the data quality behind the metrics.

## Business Opportunity

The dashboard estimates the potential quarterly SLA-credit exposure reduction from reducing the SLA breach rate toward the proposed 6% target.

This is presented as a forecast, not guaranteed savings.

## Technology

- React
- TypeScript
- Vite
- Google Gemini API
- CSV-based support data

## AI Usage Disclosure

Google Gemini was used to generate the complaint-theme summary.

OpenAI API was initially tested but could not be used because the available API account had no remaining credits. The implementation was switched to Google Gemini.

## Limitations

The AI-generated digest is an assistive summary and may occasionally miss or phrase a complaint theme differently from the underlying tickets.

For this reason, authoritative operational numbers are calculated independently from the dataset rather than generated by AI.

## Scope

This prototype focuses on support-operations intelligence.

The following were intentionally kept out of scope:

- Customer-facing chatbot
- Authentication
- Live helpdesk integration
- Full support-platform functionality
